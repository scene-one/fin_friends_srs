# fin_friends_srs

핀프렌즈(fin_friends) PRD를 SRS(Software Requirements Specification) 형태로 변환하는 작업 저장소입니다.

## 작업 목표

이 저장소의 목표는 **SRS 표준(IEEE 830 등)을 전부 만족하는 풀 스펙 문서를 새로 작성하는 것이 아닙니다.**

대신 다음 두 가지를 목표로 합니다.

1. **예시 SRS 문서의 포맷을 따르는 변환**
   기존 PRD 문서(`PRD_핀프렌즈_v0_2.md`)의 내용을, 별도로 제공되는 예시 SRS 문서에 사용된 "추가된 포맷"(예시 문서에서 실제로 사용하고 있는 섹션 구성·표현 방식)에 맞춰 옮겨 담습니다. 표준 문서 구조를 처음부터 새로 설계하지 않고, 예시 문서의 범위와 형식을 기준으로 삼습니다.

2. **예시 문서의 범위를 벗어나는 내용만 표준 포맷으로 확장**
   PRD에는 있지만 예시 SRS 문서의 다루는 범위에는 없는 내용(예: 예시 문서에 대응 섹션 자체가 없는 요구사항 유형)이 있는 경우에 한해서, 그 부분만 SRS 표준 포맷의 구성(예: 기능 요구사항, 비기능 요구사항, 인터페이스 요구사항 등 표준 섹션 분류)을 참고하여 확장 작성합니다. 문서 전체를 표준 포맷으로 새로 짜는 것이 아니라, 예시 문서에 없는 부분만 국소적으로 보강하는 방식입니다.

즉, **"예시 SRS 문서 = 기준 포맷"**이며, PRD 전체를 이 기준 포맷에 맞춰 옮기되, 기준 포맷이 커버하지 못하는 부분만 표준에 따라 확장합니다.

## 현재 상태

- `PRD_핀프렌즈_v0_2.md`: 변환 대상 원본 PRD 문서
- 예시 SRS 문서: 아직 저장소에 추가되지 않음 (추가되는 대로 해당 포맷을 기준으로 변환 작업을 진행할 예정)

## 진행 순서

1. 예시 SRS 문서 확보 및 포맷 분석
2. PRD 내용을 예시 문서 포맷에 맞춰 섹션별로 매핑
3. 예시 문서 범위를 벗어나는 PRD 내용 식별
4. 벗어나는 내용에 한해 SRS 표준 포맷 구성을 적용해 확장 작성
5. 최종 SRS 문서 통합 및 검토
